## 🧠 Selected Research Projects

**1. ECG-Based Arrhythmia Classification | B.Sc. Thesis**

- Developed a machine learning and deep learning pipeline for classifying five cardiac beat categories using the MIT-BIH Arrhythmia Database.
- Implemented ANN, DNN, CNN, KNN, Decision Tree, and Random Forest models.
- Applied wavelet-based denoising, normalization, feature extraction, and class balancing.
- Achieved 98.9% classification accuracy using a Deep Neural Network.

**2. Self-Powered IoT Smartband for Health Monitoring | BIOSEN Group**

- Contributed to the development of a wearable health-monitoring system integrating ECG, PPG, and motion sensors.
- Worked with MAX30003, MAX30102, ADXL362, and nRF52832.
- Explored thermoelectric energy harvesting for ultra-low-power operation.
- Integrated BLE communication with Android and web-based platforms.
- Related research work: *Clinical IoT in Practice: Design and Development of a Self-Power Smartband for Health Monitoring.*

**3. Clinical fMRI Analysis & 3D Brain Tumor Segmentation**

- Developed neuroimaging workflows for clinical task-based fMRI analysis.
- Worked with FSL, DICOM/NIfTI conversion, brain extraction, registration, and functional activation analysis.
- Developed a reproducible 3D U-Net segmentation pipeline for multimodal brain MRI, using PyTorch and MONAI.
- Worked with FLAIR, T1-weighted, T1-gadolinium, and T2-weighted MRI modalities.

**4. Optimized Type-2 Fuzzy Controller for Chemotherapy**

- Developed a Type-2 fuzzy logic controller for chemotherapy administration in a nonlinear tumor-growth model.
- Applied the Slime Mould Algorithm (SMA) to optimize fuzzy membership functions.
- Implemented and evaluated the control system using MATLAB/Simulink.

**5. Additional Machine Learning & Image Processing Projects**
